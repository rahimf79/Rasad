# 🎯 رصد بازار | نسخه شیشه‌ای

> **«بازار رو رصد کن، خبر رو لحظه‌ای بخون، تحلیل رو با یه نگاه بگیر»**

---

## ✨ چیه این پروژه؟

**رصد بازار** یه داشبورد لایو و شیشه‌ایه که همه چیز رو یه جا جمع کرده:

- 💰 قیمت لحظه‌ای ارز، طلا، سکه و کریپتو
- 📰 اخبار فارسی از منابع معتبر (بی‌بی‌سی، مهر، ایرنا، زومیت و...)
- 📊 تحلیل تکنیکال خودکار با RSI و میانگین‌های متحرک
- 🚗 قیمت روز خودرو از اسب‌بخار
- 🎬 ریلز خبری شبیه اینستاگرام
- 🧩 اکسپلورر گرید مدرن
- 🤖 تحلیل هوشمند روزانه اخبار
- 📄 خروجی PDF از خلاصه روز

همه اینا توی یه رابط کاربری شیشه‌ای (Glassmorphism) با تم تیره/روشن و کاملاً ریسپانسیو!

---

## 🚀 قابلیت‌ها

### 📈 قیمت‌های لحظه‌ای
| بازار | منبع | بروزرسانی |
|-------|------|-----------|
| دلار، یورو، پوند، درهم، لیر، تتر | [TGJU](https://tgju.org) | هر ۵ ثانیه |
| طلا ۱۸ و ۲۴ عیار، سکه، مثقال | [TGJU](https://tgju.org) | هر ۵ ثانیه |
| بیت‌کوین، اتریوم و ۵۰ رمزارز برتر | [CoinGecko](https://coingecko.com) | هر ۵ ثانیه |
| قیمت خودرو | [اسب‌بخار](https://sabasb.com) | دستی / خودکار |

### 📰 اخبار و رسانه
- **۵ منبع خبری معتبر فارسی** + امکان افزودن کانال تلگرام
- **دسته‌بندی هوشمند**: اقتصاد، سیاست، فناوری، ورزش، ایران، جهان، سلامت
- **ریلز خبری**: اسکرول عمودی شبیه اینستاگرام با تصویر پس‌زمینه
- **اکسپلورر گرید**: نمایش شبکه‌ای خبرها با کارت‌های بزرگ و کوچک
- **تحلیل امروز**: خلاصه و تحلیل خودکار اخبار ۲۴ ساعت گذشته

### 📊 تحلیل تکنیکال
- محاسبه RSI، میانگین ۷ و ۳۰ روزه
- تشخیص روند (صعودی / نزولی / خنثی)
- سطح حمایت و مقاومت
- سیگنال خرید / فروش / نگهداری
- نمودار شمعی لحظه‌ای

### 🎨 شخصی‌سازی
- 🌗 تم تیره / روشن
- 🎨 ۷ رنگ اصلی قابل انتخاب
- ⚡ تنظیم سرعت تیکر
- 🔢 تعداد اخبار (۱۰ تا ۱۲۰)
- 📺 نمایش/مخفی کردن نوارهای تیکر

## 🛠️ تکنولوژی‌ها

```
HTML5  +  CSS3 (Glassmorphism)  +  Vanilla JavaScript
Chart.js  (نمودارها)
html2pdf.js  (خروجی PDF)
RSS2JSON API  (دریافت خبر)
TGJU API  (قیمت‌های ایران)
CoinGecko API  (رمزارزها)
```

> بدون هیچ فریم‌ورک سنگینی! فقط کد خالص و بهینه 🔥

## 📱 نحوه استفاده

### ۱. باز کردن فایل
فایل `akhbar-bazar-glass.html` رو توی مرورگر باز کن (Chrome, Firefox, Safari, Edge).

### ۲. تب‌ها
| آیکون | نام | توضیح |
|-------|-----|-------|
| 📰 | اخبار | اخبار با نمایش لیست / اکسپلورر / ریلز |
| 💱 | ارز | دلار، یورو، طلا، سکه |
| ₿ | کریپتو | ۵۰ رمزارز برتر |
| 🚗 | خودرو | قیمت روز خودروهای ایران |
| 📊 | تحلیل | تحلیل تکنیکال همه دارایی‌ها |

### ۳. تنظیمات
روی ⚙️ بزن و:
- منابع خبری رو انتخاب کن
- کانال تلگرام اضافه کن
- رنگ و تم رو عوض کن
- سرعت تیکر رو تنظیم کن

### ۴. ذخیره تنظیمات
همه چی توی `localStorage` مرورگر ذخیره می‌شه. پاک کردن کش = ریست تنظیمات.
