## ✨ این نسخه چه چیزی را عوض کرد؟

نسخهٔ قبلی یک داشبورد تک‌صفحه‌ای بود. حالا کل برنامه به یک **شبکهٔ اجتماعی خبری به سبک اینستاگرام** تبدیل شده است:

| خواسته | پیاده‌سازی |
|---|---|
| لوگوتایپ مشابه اینستاگرام | `assets/img/logo.svg` و نسخهٔ درون‌خطی در هدر (گرادیان زرد→نارنجی→سرخابی→بنفش + واژه‌نمایش خط‌شکستهٔ Grand Hotel) + آیکون «رادار/نبض بازار» |
| هر خبرگزاری یک صفحه داشته باشد | `#/u/{handle}` — آواتار با حلقهٔ استوری، آمار، بیو، دکمهٔ دنبال کردن، تب‌های **پست‌ها / استوری‌ها / آرشیو** و گرید سه‌ستونی |
| پست و استوری از سمت همان خبرگزاری | هر آیتم RSS به «پست» تبدیل می‌شود؛ موارد منتشرشده در ۲۴ ساعت گذشته هم‌زمان «استوری» همان صفحه‌اند |
| استوری ۲۴ ساعته، پست بدون انقضا | `APP.STORY_TTL_MS = 24h` در `config.js`؛ تابع `isStory()` در `posts.js` (با آزمون مرز ۲۳/۲۵ ساعت) |
| جمع‌آوری مرتب + آرشیو با تاریخ دقیق | GitHub Actions هر ۳۰ دقیقه + جمع‌آوری زنده در مرورگر؛ هر خبر با `date` و `exactDate` جلالی (تا ثانیه) در `data/news/YYYY-MM-DD.json` |
| ریلز به سبک اینستاگرام | اسکرول عمودی با snap، ریل کناری (لایک/کامنت/اشتراک)، زوم تدریجی تصویر، شمارنده |
| سرچ به سبک اینستاگرام | کادر جست‌وجوی زنده + نتایج تفکیک‌شده (خبرگزاری‌ها / قیمت‌ها / هشتگ‌ها / پست‌ها) + جست‌وجوهای اخیر + گرید اکسپلور |
| قیمت ارز، طلا، سکه، نفت، گاز و انرژی **حتماً از ثروتمندی** | ۵۵ دارایی با کد Entity مستقیم از `servatmandi.com` (جدول کامل پایین‌تر) |
| قیمت خودرو از باما | `bama.ir` (صفحهٔ قیمت و برندها) با پارسر اختصاصی |
| نمودار با جزئیات کامل زمان | نمودار SVG با شبکه، محور جلالی و نقاط قابل‌هاور؛ جدول «قیمت در هر زمان» + آمار بازه (بیشینه/کمینه/میانگین/تغییر و تاریخ دقیق سقف و کف) |
| صفحهٔ اختصاصی قیمت + کامنت زیر آن | `#/price/{key}` — نمودار + مشخصات + تاریخچه + بخش کامنت |
| کامنت فقط با حساب کاربری | `Store.addComment()` در نبود نشست `AuthError` پرتاب می‌کند؛ فرم کامنت برای مهمان با قفل جایگزین می‌شود |
| UI شیشه‌ای و دلنشین | سیستم طراحی Glassmorphism (`assets/css/app.css`) با تم تیره/روشن، انیمیشن، و چیدمان RTL |
| اجرای خودکار روی GitHub Pages + ذخیرهٔ داده | دو ورک‌فلو: `deploy.yml` و `collect.yml` + سه لایهٔ ذخیره‌سازی (پایین‌تر توضیح داده شده) |

## 💹 منابع قیمت

### ثروتمندی (`servatmandi.com`) — منبع اصلی و الزامی

قیمت‌ها مستقیماً از صفحهٔ `https://servatmandi.com/Entity/Summary/{code}` خوانده می‌شوند
(آخرین قیمت، اولین، بیشترین، کمترین، قیمت روز کاری قبلی و **زمان دقیق جلالی تا ثانیه**).
مقادیر ریالی به تومان تبدیل می‌شوند.

| گروه | نمونه دارایی‌ها (کد Entity) |
|---|---|
| ارز | دلار آمریکا `100000000001`، یورو `100000000002`، پوند `100000000008`، درهم `100000000005`، لیر `100000000006`، یوان `100000000007`، فرانک `100000000012`، ۱۰۰ ین `100000000016`، دلار کانادا/استرالیا، روبل، دینار عراق/کویت، ریال عربستان/قطر، افغانی، منات، دلار حواله دولتی `200000000001`، شاخص دلار ثروتمندی `800000` |
| طلا و سکه | طلای ۱۸ عیار `5000000001102`، مظنه طلا `5000000001000`، سکه امامی `5000000001202`، نقره ۹۹۹ `50000000001301`، انس طلا `10000000001901`، انس نقره `10000000001903` |
| نفت، گاز و انرژی | برنت `10000000002001`، WTI `10000000002000`، گاز طبیعی `10000000002002`، TTF هلند `10000000002006`، NBP انگلستان `10000000002007`، گاز آلمان `10000000002014`، LNG `10000000002016`، بنزین `10000000002003`، نفت کوره `10000000002004`، گازوئیل `10000000002009`، پروپان `10000000002010`، زغال سنگ `10000000002005`، زغال کک `10000000002015`، اورانیوم `10000000002011`، اتانول، متانول، نفت اورال |
| ارز دیجیتال | تتر `5000000000000`، بیت‌کوین `920000`، اتریوم `920001`، پکس گلد `910001`، تتر گلد `910000` |

علاوه بر این، `collect.mjs` در هر اجرا دیدبان‌های `Entities/1..6` را پیمایش می‌کند و دارایی‌های جدید را
در `data/entities.json` کشف و ثبت می‌کند (تا با افزودن نماد جدید در ثروتمندی، لازم به تغییر کد نباشد).

### باما (`bama.ir`) — قیمت خودرو
صفحهٔ قیمت روز و صفحهٔ برندها پارس می‌شوند؛ نتیجه در `data/cars.json` و در تب **بازار** با گروه «خودرو» نمایش داده می‌شود.
اگر ساختار صفحهٔ باما تغییر کند و پارسر چیزی پیدا نکند، برنامه بدون خطا ادامه می‌دهد و فقط آن بخش خالی می‌ماند.

## 🗄️ ذخیره‌سازی: GitHub Pages دیتابیس ندارد، پس سه لایه داریم

GitHub Pages فقط فایل استاتیک سرو می‌کند. برای اینکه داده‌ها **ریست نشوند** و **با مرور زمان حذف شوند**:

1. **IndexedDB مرورگر** — حساب‌ها، دنبال‌شونده‌ها، لایک، ذخیره، کامنت‌ها و آرشیو محلی. با رفرش پاک نمی‌شود.
2. **مخزن گیت به‌عنوان دیتابیس** — `collect.yml` هر ۳۰ دقیقه اجرا می‌شود، اخبار و قیمت‌ها را جمع می‌کند و
   `data/*.json` را کامیت می‌کند. این داده بین همهٔ کاربران مشترک است و هرگز با پاک شدن کش مرورگر از بین نمی‌رود.
3. **همگام‌سازی اختیاری با GitHub Contents API** — در `#/settings` می‌توانید یک توکن (fine-grained PAT با دسترسی
   `Contents: Read & Write`) بدهید تا کاربران، دنبال‌شونده‌ها و کامنت‌ها مستقیم روی مخزن (پوشهٔ `user-data/`) نوشته شوند.
   دکمه‌های «آزمون اتصال» و «دریافت از گیت‌هاب» هم در همان بخش است.

### سیاست نگهداری (حذف تدریجی)
```js
RETENTION = { newsDays: 120, priceDays: 1095, commentsDays: 3650 }
```
- اخبار قدیمی‌تر از ۱۲۰ روز از آرشیو حذف می‌شوند (`pruneNews`).
- نقاط قیمتی قدیمی‌تر از ۳ سال حذف می‌شوند (`prunePrices`).
- پست‌ها در برنامه تاریخ انقضا ندارند؛ فقط استوری‌ها ۲۴ ساعته‌اند.
- هر دو مقدار در تنظیمات قابل تغییر است.

## 🚀 فعال‌سازی روی GitHub Pages

1. در ریپو: **Settings → Pages → Build and deployment → Source** را روی **GitHub Actions** بگذارید.
2. کد را به شاخهٔ پیش‌فرض (`main`) مرج کنید؛ `deploy.yml` به‌صورت خودکار تست‌ها را اجرا کرده و سایت را منتشر می‌کند.
3. `collect.yml` هم پس از مرج روی `main` به‌صورت زمان‌بندی‌شده (هر ۳۰ دقیقه) فعال می‌شود.
   > نکته: GitHub طبق سیاست خود، `schedule` را فقط روی شاخهٔ پیش‌فرض اجرا می‌کند. قبل از مرج می‌توانید از
   > تب **Actions → Collect news and prices → Run workflow** دستی اجرا بگیرید.
4. اگر می‌خواهید روی دامنهٔ اختصاصی منتشر شود، فایل `CNAME` را در ریشه اضافه کنید (ورک‌فلو خودش آن را به خروجی اضافه می‌کند).

### اجرای محلی
> نیازمند **Node ۲۲.۱۹ یا بالاتر** (وابستگی jsdom یعنی undici به `worker_threads.markAsUncloneable` نیاز دارد).
> روی Node ۲۰ تست یکپارچهٔ jsdom با خطای `markAsUncloneable is not a function` می‌افتد.

```bash
npm install
npm run serve     # http://localhost:4173
npm test          # ۸۷ آزمون
node scripts/lint-html.mjs
node scripts/collect.mjs --dry   # جمع‌آوری بدون نوشتن روی دیسک
```

## 🧪 چه چیزی تست شده است؟

`npm test` → **۸۷ آزمون** با `node:test`:

- **تاریخ جلالی**: رفت‌وبرگشت ۱۲۰۰ روزه، و `۱۴۰۵/۰۶/۳۰ = ۲۰۲۶/۰۹/۲۱` (همان تاریخی که روی صفحهٔ ثروتمندی دیده شد).
- **پارسرها**: RSS/Atom با CDATA، صفحهٔ خلاصهٔ ثروتمندی در دو قالب HTML و markdown، کشف دارایی‌ها، قیمت خودروی باما، تاریخچهٔ TGJU.
- **دیتابیس**: ثبت‌نام/ورود/خروج، عدم نشت هش رمز، **ممنوعیت کامنت بدون ورود**، حذف کامنت فقط توسط نویسنده، دنبال کردن، آرشیو بدون تکراری، پاک‌سازی بر اساس سیاست نگهداری، پشتیبان‌گیری.
- **استوری**: مرز دقیق ۲۴ ساعت، گروه‌بندی بر اساس خبرگزاری، دیده‌شده/دیده‌نشده.
- **قیمت**: تبدیل ریال→تومان، درصد تغییر، آمار بازه، «قیمت در فلان زمان»، تولید SVG نمودار.
- **یکپارچه با jsdom**: همان `index.html` و همان ماژول‌ها بارگذاری می‌شوند؛ مسیر واقعی
  `fetch → parseRss → normalizeItem → Store → render → DOM` بررسی می‌شود،
  شامل باز شدن صفحهٔ خبرگزاری، رسم نمودار قیمت، قفل بودن کامنت برای مهمان، ثبت کامنت پس از ورود،
  و باز شدن مودال ورود هنگام زدن «دنبال کردن».

> ⚠️ محدودیت راستی‌آزمایی: در محیط توسعهٔ این تغییرات، خروجی شبکه به‌جز `api.github.com` بسته بود،
> بنابراین **خودِ درخواست‌های شبکه به ثروتمندی/باما/خبرگزاری‌ها به‌صورت زنده اجرا نشدند**.
> آنچه اجرا شد: اجرای کامل `scripts/collect.mjs` (که همهٔ مسیرهای خطا را بدون crash پیمود)،
> پارسرها روی نمونه‌های واقعیِ صفحه‌ها، و کل منطق برنامه در jsdom با پاسخ‌های شبیه‌سازی‌شده.
> اولین اجرای `collect.yml` روی GitHub Actions راستی‌آزمایی نهایی زنده است.

## ⚠️ سلب مسئولیت

> این پروژه صرفاً یک ابزار اطلاع‌رسانی است و هیچ‌گونه توصیهٔ مالی، سرمایه‌گذاری یا معاملاتی ارائه نمی‌دهد.

1. قیمت‌ها از منابع عمومی (ثروتمندی، باما) خوانده می‌شوند و ممکن است با قیمت واقعی بازار تفاوت داشته باشند.
2. محتوای خبرها متعلق به خبرگزاری‌های منبع است؛ این پروژه مسئولیتی در قبال صحت آن ندارد.
3. استفادهٔ غیرمجاز، سوءاستفاده از APIها یا فعالیت مغایر قوانین ممنوع است.
4. این نرم‌افزار «آن‌گونه که هست» و بدون هیچ ضمانتی ارائه می‌شود.
5. مسئولیت هر تصمیم مالی بر عهدهٔ کاربر است.
6. اگر همگام‌سازی گیت‌هاب را فعال می‌کنید، توکن را با دسترسی محدود (فقط همان مخزن) بسازید؛ توکن در `localStorage` همان مرورگر ذخیره می‌شود.
